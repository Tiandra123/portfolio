# Machine Learning Coursework
 
Assignments from the Machine Learning course (USU, M.S. MIS). Each notebook covers a different ML concept — from exploratory analysis and regression to classification and dimensionality reduction.
 
---
 
| File | Description |
|------|-------------|
| `BasicEDA.ipynb` | Exploratory data analysis on NYC real estate sales data. Covers data cleaning, null handling, and outlier identification. |
| `KNN.ipynb` | KNN regression on bike sharing data to predict rental counts. Includes cross-validation to find optimal k and comparison against linear regression. |
| `LinearRegressionModel.ipynb` | Linear regression using NYC real estate and Boston housing data. Explores polynomial features and the bias-variance tradeoff. |
| `Linear_Ridge_ElasticNet_LASSO.ipynb` | Comparison of Ridge, LASSO, and Elastic Net regularization techniques to control model complexity and prevent overfitting. |
| `LogisticRegression.ipynb` | Introduction to classification — predicting categories and probabilities using logistic regression. |
| `PCA.ipynb` | Dimensionality reduction using Principal Component Analysis to identify key patterns and visualize high-dimensional data. |
| `RandomForest.ipynb` | Ensemble learning with random forests for regression and classification tasks, including feature importance analysis. |
 
---
 
*All notebooks developed in Google Colab using pandas, NumPy, Matplotlib, Seaborn, and scikit-learn.*
