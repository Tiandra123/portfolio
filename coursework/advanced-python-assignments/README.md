# Advanced Python Coursework
 
Assignments from the Advanced Python course (USU, M.S. MIS). Projects cover network algorithms, API integration, data analysis, and applied Python fundamentals.
 
---
 
| File | Description |
|------|-------------|
| `crypto_arbitrage.py` | Network-based arbitrage detection for cryptocurrency markets using graph theory. Retrieves real-time price data and traverses the graph to identify trading opportunities across multiple currencies. |
| `covid_analysis.py` | Data analysis tool that pulls COVID-19 statistics for all US states and territories via REST API, performs statistical analysis, and outputs per-state JSON files. |
| `blackjack.py` | Command-line Blackjack game with full game logic — card dealing, score tracking, bust detection, house play rules, and win/loss evaluation. |
| `energy_analysis.py` | Energy efficiency analysis across Western US states using the U.S. Energy Information Administration API. Analyzes multiple fuel types and calculates efficiency metrics by state. |
 
---
 
*All projects developed on AWS EC2 via VS Code remote development.*
